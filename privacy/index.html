Privacy

Simple and private.

This website does not use cookies, trackers or advertising.

Your language, sound and appearance choices are stored only in your own browser, so the site remembers them next time.

The application form does not send anything to a server. It prepares a message on your device, and you decide whether to send it to us on Instagram.

The site is hosted on GitHub Pages. Like any web host, GitHub may process technical data such as your IP address to deliver the site securely.
